Role management is not active yet.

This app is currently in open-access mode. Apply sql/14_user_permissions.sql, verify that Supabase Auth users and profile rows are ready, then set OPEN_ACCESS to false in js/config.js. The access setting was left unchanged so nobody is locked out.

Actions unavailable to the selected role stay disabled. Page settings can reduce that role's access; they cannot grant actions beyond the role's existing limits. Admin accounts retain full access. These controls restrict the app interface; Supabase RLS policies remain the server-side data security boundary.
